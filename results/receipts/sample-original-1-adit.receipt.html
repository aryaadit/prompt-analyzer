In plain words, with every term the page uses explained.

The agent works in steps: one call to the model, the tool calls it made, and what came back. Every call sends the whole conversation so far. Material the model has just seen is new; material sent again on a later call is re-sent (carried cost). A step's cost is its own output plus what its results cost to send, now and on every later call.

The page has three layers: the answer at the top, the explanation under it, and the evidence in the sections that open and close. Every number carries a small word: exact means it was read from the log, est. means a fixed rule worked it out from the exact numbers. Colour is never the only cue; each colour sits next to its name.

Glossary

API-equivalent
Tokens multiplied by the public prices that companies pay when they use the model through the API. On a flat monthly plan nobody is billed this amount. It is a yardstick, not a bill.
re-sent
Material the model already saw on an earlier call, sent again. Every call sends the whole conversation so far. The provider charges a lower price for it, but it is paid for on every call.
new
Material sent for the first time on a call: what you typed, what a tool just returned, the model's last reply. It is charged at the higher price for fresh input.
carried cost
What it costs to re-send something on every later call. A big file read early is carried through the rest of the session, so it is paid for many times.
cache rebuild
The provider keeps a saved copy of the conversation for a few minutes. After a pause the copy expires, and the next call has to write the whole conversation again at a higher price.
starting context
Everything Claude Code sends before you type anything: its own instructions, the tool definitions, and any project instruction files. It is sent on every call.
exact
Read straight from the session log, with no guessing.
est.
Estimated: worked out by a fixed rule from the exact numbers. The log does not record it directly.
step
One call to the model, the tool calls it made, and what came back.
model call
One request to the model. A single prompt from you can trigger dozens.
token
The unit models read and write, about three quarters of an English word. Usage is counted in tokens.
compaction
When a long conversation is summarized to free up room. The earlier material is replaced by the summary, so it stops being re-sent.
thinking
The model's own reasoning before it answers. It is billed as output.
subagent
A helper agent that Claude Code starts for a side task. It has its own conversation, and its exact cost is added to the step that started it.

The method, the prices and the date they were checked, how the totals were validated, and what the numbers cannot tell you.

What is exact and what is estimated

  • Exact: tokens of every model call, the total, the largest prompt (56,202 tokens), thinking tokens, and each step's output cost.
  • Est.: how the input bill is split between items. The log records tokens per call, not per file or per tool. Result sizes come from how much the prompt grew after each step; typed prompts are sized at 2.6 characters per token.
  • The split always adds back up to the exact transcript total (checked on every build: difference $0.000000000).

Known limits

  • 0 step(s) had growth smaller than the previous output (context trimmed or thinking dropped), so their results could not be sized from growth.
  • 0 call(s) were flagged "cache rebuilt": they paid for more than twice the new tokens, and at least 5,000 more.
  • Searches and file reads hidden inside Bash commands are found by a word table, so those lines are estimates. 0% of 0 Bash calls could not be classified.
  • Work done by subagents is added to the step that launched it, as one exact amount. It is not broken down here, and files read by subagents are not in the Files table.
  • Subagents that no step launched: 0.
